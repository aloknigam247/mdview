# Code samples

A simple Rust example:

```rust
fn main() {
    let msg = "hello, world";
    println!("{msg}");
}
```

A Python snippet:

```python
def greet(name: str) -> str:
    return f"hello, {name}"

print(greet("world"))
```

Some JavaScript:

const add = (a, b) => a + b;
console.log(add(2, 3));
