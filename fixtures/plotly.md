# Plotly fixture

A simple scatter plot served via the mdview plotly extension.

```plotly
{
  "data": [
    {
      "x": [1, 2, 3, 4, 5],
      "y": [4, 1, 3, 5, 2],
      "type": "scatter",
      "mode": "lines+markers",
      "name": "demo series"
    }
  ],
  "layout": {
    "title": "mdview plotly demo",
    "margin": {"t": 40, "r": 20, "l": 40, "b": 40}
  }
}
```
